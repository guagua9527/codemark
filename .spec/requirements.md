# CodeMark 需求文档

> AI + 批注驱动的 LLM 开发框架

## 项目概述

CodeMark 是一个基于 AI 的开发框架，核心理念是**批注驱动开发**（Annotation-Driven Development）。用户可以在 Web 页面上像 Word 批注一样标记代码问题，AI 自动理解批注并修改代码。

## 核心需求

### 1. Spec & Plan 驱动的代码生成

**目标**：用户编写需求规格文档，AI 自动生成代码

- 支持 `.spec` 目录下的 Markdown 需求文档
- LLM 解析 spec 文件，生成项目计划（plan）
- 根据 plan 自动生成前后端代码
- 支持增量更新（spec 变更时只更新相关代码）

### 2. Web 批注模式（核心功能）

**目标**：在 Web 页面上实现类似 Word 批注的交互方式

**功能点**：
- 用户可以选中页面上的任意元素/区域
- 弹出批注输入框，用户可以输入问题或改进方向
- 批注以可视化标记显示在页面上（气泡、高亮等）
- 批注支持回复、解决状态管理
- 批注与具体的 DOM 元素/组件绑定

**交互设计**：
- 点击批注标记 → 展开详情
- 拖拽选择区域 → 创建新批注
- 批注列表面板 → 查看所有批注

### 3. AI 自动修复

**目标**：AI 根据批注内容自动修改代码

**流程**：
1. 用户提交批注（如"这个按钮点击没反应"）
2. 系统定位到相关代码（通过 DOM → 组件映射）
3. AI 分析批注 + 上下文代码
4. 生成修复方案并自动应用
5. 热更新页面，用户可立即验证

**要求**：
- 批注需要关联到具体的代码位置
- AI 需要理解前端组件和后端接口的关系
- 修改后需要自动运行相关测试

### 4. 框架与项目解耦

**目标**：CodeMark 作为开发工具，不侵入用户项目

**设计原则**：
- CodeMark 仅在 dev 阶段存在
- 生产构建时完全移除 CodeMark 相关代码
- 通过中间件/插件方式注入，不修改用户项目结构
- 前后端均以 devDependency 形式引入

**技术方案**：
- 前端：Vite/Webpack 插件注入批注 UI
- 后端：Express/Koa 中间件拦截和增强
- 构建时自动清理所有 CodeMark 相关代码

### 5. 错误日志系统

**目标**：全面捕获和监听应用错误

**前端监控**：
- 捕获 `console.error/warn` 输出
- 监听未处理的 `Promise rejection`
- 监听 `window.onerror` 全局错误
- 捕获 React/Vue 组件错误边界
- 错误自动关联到批注系统

**后端监控**：
- 捕获 stdout/stderr 输出
- 监听未捕获异常
- API 请求/响应日志
- 错误堆栈解析和定位

**错误 → 批注联动**：
- 检测到运行时错误时，自动在对应位置创建批注
- 批注包含错误信息、堆栈、复现步骤

## 技术栈（待定）

| 层级 | 候选方案 |
|------|----------|
| 前端批注 UI | 自研组件 / Highlight.js + 自定义层 |
| 前端框架适配 | Vite 插件 / Webpack 插件 |
| 后端中间件 | Express / Koa / Fastify |
| AI 集成 | OpenAI API / Claude API / 本地模型 |
| 错误收集 | 自研 / Sentry 集成 |
| 通信 | WebSocket（实时批注同步） |

## 项目结构（初步）

│   ├── vite-plugin/       # Vite 插件
│   ├── webpack-plugin/    # Webpack 插件
│   ├── server-middleware/ # 后端中间件

## 验收标准

- [ ] 用户可以通过 spec 文件生成完整项目
- [ ] Web 页面支持选中元素并添加批注
- [ ] 批注可以关联到具体代码位置
- [ ] AI 能根据批注自动修改代码并热更新
- [ ] 生产构建完全移除 CodeMark 代码
- [ ] 前后端错误自动捕获并生成批注
- [ ] 支持 Vue 3 和 React 18+
